# Olympic Medal Trends

### Geography, Seasonality and Host Nation Performance (1896–2016)

An interactive data visualization project exploring historical Olympic medal distribution, host nation performance and sport-specific trends.

**[View the interactive website](https://actually-arri.github.io/Olympic_Medal_Trends/)**

## Overview

This project explores Olympic performance through four interactive dashboards:

- Host nation performance and medal distribution
- Historical medal trends across Summer and Winter Olympics
- Sport-specific medal distribution
- Medal concentration across host cities

[Original Group Project](https://github.com/AdwaitKulkarni58/DSCI320-project-website)

## Running Locally

Download or clone this repository.

From the project directory, run:

`python3 -m http.server 8000`

Open `http://localhost:8000` in your browser.
